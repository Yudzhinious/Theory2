# 10-дневный курс подготовки к собеседованию по Java

Курс составлен на основе вопросов из PDF-файлов проекта (`гемини классные ответы.pdf` и `Копия_Копия_sql_operators_overview_ruresulting_1.pdf`) и расширен дополнительной теорией. Идём от основ к сложному.

В каждой папке `DayNN_...` два файла:
- **`Теория.md`** — развёрнутый материал по теме дня с примерами.
- **`Вопросы.md`** — вопросы для самопроверки (включая практические задачи).

## Как заниматься

1. **Утро** — читаешь `Теория.md` текущего дня, конспектируешь ключевое.
2. **День** — пишешь небольшие примеры кода по каждой теме (особенно коллекции, многопоточность, streams, SQL).
3. **Вечер** — проходишь `Вопросы.md` вслух, без подглядывания; затем проверяешь себя по теории.
4. На следующий день — 10–15 минут повторения вчерашней темы.
5. Последний день (или выходной) — повторяешь шпаргалки из всех дней.

## Приоритеты на собеседовании

Наиболее часто спрашивают: JVM/JIT/память, equals/hashCode, String, коллекции и HashMap внутри, многопоточность (synchronized/Lock/volatile/пулы), исключения, Stream API, JDBC/транзакции/уровни изоляции, Spring (IoC/DI, жизненный цикл бина, @Transactional), REST. Удели им особое внимание.
