## Практика
43. Что выведет?
```java
class A {
  static { System.out.print("A-static "); }
  { System.out.print("A-init "); }
  A(){ System.out.print("A-ctor "); }
}
class B extends A {
  static { System.out.print("B-static "); }
  { System.out.print("B-init "); }
  B(){ System.out.print("B-ctor "); }
}
new B(); new B();
```
